# Security Policy

## Supported projects

This repository is a portfolio monorepo. Security fixes are accepted for all actively maintained project folders.

## Reporting a vulnerability

Please do not file public issues for sensitive vulnerabilities.

Instead:
1. Open a private security advisory if available.
2. Or contact the maintainer directly via GitHub profile contact.

Include:
- Affected project folder
- Steps to reproduce
- Potential impact
- Suggested mitigation (if known)

You should receive an acknowledgment within 72 hours.
