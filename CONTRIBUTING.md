# Contributing

Thanks for your interest in contributing.

## How to contribute

1. Fork the repo.
2. Create a branch from `main`.
3. Make focused changes in one project folder.
4. Add or update tests.
5. Open a pull request with clear notes.

## Pull request checklist

- [ ] Code builds or runs locally
- [ ] Tests pass locally
- [ ] README/docs updated if behavior changed
- [ ] No unrelated file changes

## Commit style

Use small, descriptive commits, for example:
- `feat(fastapi-task-api): add pagination to list endpoint`
- `fix(dev-journal-cli): handle empty tag input`
